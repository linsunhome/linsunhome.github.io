把基础模型能力，变成可被理解、验证和使用的真实能力。

孙林，360 算法高级研究员、基础大模型团队负责人。长期从事基础模型、后训练、大模型安全、RAG、记忆与 Agent 系统的研究和工程实践。

我先后在腾讯、360、贝壳找房与如视等团队从事推荐系统、搜索问答、数据智能、基础模型和大模型安全工作；目前在 360 负责基础大模型团队，连接研究、工程、团队建设与线上交付。近年来的研究成果发表于 NeurIPS、ACL、EMNLP、AAAI、ECAI、ICASSP 等会议和期刊，并围绕大模型安全、RAG、记忆和 Agent 系统形成持续的公开研究与产业实践，相关团队成果获得北京市科学技术进步二等奖、SafetyAI Bench 连续两次第一和 SuperCLUE-RAG 评测第一等认可。
