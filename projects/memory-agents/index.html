Research / Project detail

记忆、经验与 Agent 系统

围绕长期状态、任务经验与真实 Agent 工作流的持续探索。

Memory Agents Evaluation
问题 / 动机

如何跨对话保持状态、从任务反馈中复用经验，并理解 Agent 的效果与运行环境之间的关系？

个人角色

推进长期记忆与经验复用方向的技术工作，参与相关研究。

技术路径

Mem360 面向长期用户状态与个性化；经验服务面向任务复盘与反馈复用。关联研究包括 Harness-Bench、MemAudit、ArborMem 与经验服务。

结果

Agent 工作流评测、记忆安全与经验服务。

方案与实验

Mem360 将记忆拆分为情景、语义和程序记忆，并结合向量库、图数据库和统一接口支持长期状态管理；相关论文讨论工作流评测、记忆安全和经验服务。
